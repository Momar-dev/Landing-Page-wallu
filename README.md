# Landing Page — Wallu

Page vitrine de l'application Wallu (super-app mobile de paiement et mise en relation).

🔹 Live / Demo : https://momar-dev.netlify.app/ (section Wallu)

🔹 Tech : HTML5 · CSS3 · JavaScript · Bootstrap

## Objectif
Présenter les fonctionnalités clés de Wallu : paiement mobile, recherche de prestataires, tarification, témoignages et appel à l'action pour télécharger l'application.

## Installation / Déploiement
```bash
git clone https://github.com/Momar-dev/Landing-Page-wallu.git
# ouvrir index.html ou déployer sur Netlify
```
